# Security policy

Do not report vulnerabilities in public issues. Use GitHub's private security
advisory workflow for this repository, including a minimal reproduction and
impact description. Do not include credentials, production URLs, user data, or
private keys in reports.

Never commit `.env` files, service-account credentials, private keys, database
dumps, or object-storage data. If a credential is exposed, revoke or rotate it
immediately before removing it from Git history.
